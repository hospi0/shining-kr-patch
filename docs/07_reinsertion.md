# 번역·재삽입 파이프라인 (2026-07-12 착수)

## 전략 요약 (지금까지 규명 기반)
- **재삽입 = (b) 우회훅 확정**: 메시지가 씬 진입 시 동적 코드북(codebook_B)으로 재컴파일 → 재압축 불가. 디코더 출력(디코드버퍼 0x0607b390의 16비트 글리프토큰)을 한글로 대체.
- **폰트**: 게임 글리프 = 32바이트 [폭2B]+[15행 1bpp 16px]. 한글 = 굴림 임베디드 비트맵(12px)로 생성(`tools/hangul_font.py`). 글리프 0x20-0x34F=고정폰트(디스크 X2SAMPLE.MES offset 0xC+), 0x350+=동적.

## 파이프라인 구성
1. **추출**: 씬 스냅샷 → `extract_dialogue.py` → 씬별 대사(docs/{forest,village,grave}_dialogue.txt). 글리프 자동식별 `build_glyph_table.py`(비트맵DB).
2. **번역 데이터**: `translation/{scene}.json` — `[{box, addr, jp, kr}]`. kr 필드 채우기.
3. **한글 폰트 생성**: `tools/hangul_font.py` — 임의 한글 음절→게임 32바이트 글리프.
4. **재삽입**:
   - (a) **글리프 배치**: 번역문의 유니크 한글 음절 수집 → 글리프 생성 → 글리프테이블 슬롯 할당(고정폰트=디스크 X2SAMPLE 편집, or 훅으로 주입).
   - (b) **토큰 주입**: 각 메시지의 한글 토큰열(글리프인덱스+공백0x20+줄바꿈0x03+종료0x08)을 디코드버퍼에 주입(런타임 훅).

## ✅ 재삽입 실증 (2026-07-12, 세이브스테이트)
PoC(글리프1자, state4)를 확장 → **완전한 한글 문장 박스** 주입 성공.
- 대상: forest box[00] "どおりで・・・オレたちが来た時/お前しか 見あたらなかったわけだ。"
- 번역: "그래서 우리가 왔을 때/너밖에 안 보였던 거군。"
- 방법: 유니크 한글 19자를 게임 글리프로 생성→글리프테이블 슬롯 0x100+에 배치(swap16), 디코드버퍼(snap 0x5fa767, 0x0607b3a0) 토큰을 한글인덱스열로 교체.
- 검증: 주입 스냅샷의 디코드버퍼+글리프표 렌더 → 완전한 한글 2줄(extract/state2/kr_mockup.png). 산출 `poc/Shining the Holy Ark (Japan) (3M).state5`.
- **스냅샷 위치**: 디코드버퍼 토큰 addr 0x0607b3a0=snap 0x5fa767(state1, swap16). 16바이트 헤더(0x0607b390) 뒤. 글리프표 addr 0x21800c+(idx-0x20)×32 = snap 0x4973ca+(addr-0x218000).

## 남은 것 (실제 패치)
- **런타임 훅**(세이브스테이트 아님): 메시지 디코드 후 디코드버퍼(0x0607b390)를 한글토큰으로 덮어쓰는 SH2 훅. 훅포인트 후보: 메시지렌더 0x606c9e4(seek+디코드 후, 렌더 전) 또는 디코더 출력부. (scene,msgid)=[0x060792d0]+씬ID로 번역 조회.
- **✅글리프 용량 전략 결정(2026-07-12): 씬별 프리컴포즈드(완성형) 로딩.**
  - **씬별 로딩**(전게임 통합 아님): 게임이 씬마다 메시지+글리프 재컴파일하는 구조와 일치. 씬당 유니크 음절 ~300-500(JP본문 유니크 forest367/village416/grave274 기준, 한글은 비슷하거나 적음) << 고정슬롯 0x20-0x34F=816개 → **용량 문제 없음**. (전게임 통합이면 ~1000-1500으로 초과하나 씬별이면 무관.)
  - **완성형**(조합형/jamo 아님): 굴림 임베디드 비트맵으로 음절 통째 생성(hangul_font.py 검증). 렌더러가 좌→우 고정폭 블릿이라 조합형 합성은 훅 복잡+품질저하 → 완성형 채택.
  - **슬롯 배치**: 한글 음절→한자범위(0x100+) 재활용(완전한글화라 한자 불필요). 0x20-0xFF는 숫자·구두점·(필요시)카타카나 유지(이름/수치/외래어 표기). 런타임 훅이 씬 진입 시 그 씬 번역의 유니크 음절을 글리프표 로드.
- ⚠️ 세이브스테이트 디코드버퍼 편집은 게임 재디코드 시 덮일 수 있음(글리프표 편집은 지속=PoC state4로 확인). state5 실기 테스트로 디코드버퍼 지속성 확인 필요.
