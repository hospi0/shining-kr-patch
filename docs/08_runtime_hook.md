# 런타임 훅 설계 (2026-07-12) — 영구 한글 패치

세이브스테이트가 아닌 **디스크 패치**로 한글 표시. 재삽입 메커니즘은 state5로 실기 검증됨(docs/07).

## 훅 지점 (확정)
메시지 렌더 `0x606c9e4`(X02.BIN) 내부:
```
0606CA1C: JSR 0x0606CB84   ; seek(msgid) — srcptr 위치
0606CA22: JSR 0x0606CE88   ; DECODE — JP 토큰을 디코드버퍼 0x0607b390에 채움
0606CA24: MOV R9,R4        ; (decode JSR 딜레이슬롯)
0606CA26: MOV #1,R1
0606CA28: MOV.W R1,@R8     ; [0x0607BB9A]=1 (렌더 위치카운터)
0606CA2A: MOV.L @(PC),R1 => 0x0607B390  ; ← 렌더 루프 시작(디코드버퍼 읽기)
```
**삽입점 = 0x606ca26 직전** (디코드 완료, 렌더 루프 전). 이 시점 디코드버퍼 0x0607b390=JP 16비트토큰(종료 0x0008/0x0004).

## 훅 로직 (내용 해시 키잉)
메시지 식별을 msgid/씬이 아니라 **디코드된 JP 토큰 내용 해시**로. (씬 대사가 table2에 없는 주소체계 문제 회피, 전 씬 통일.)
```
my_hook:
  1. 디코드버퍼 0x0607b390 토큰을 종료(0x0008/0x0004)까지 읽어 해시 계산(FNV-1a 등)
  2. 번역테이블[해시] → 한글 토큰배열 검색
  3. 매치: 한글 토큰을 0x0607b390에 복사(종료 포함)
  4. 원 오버라이트 명령([0x0607BB9A]=1) 수행 후 0x606ca2a로 복귀
```
- 동일 JP → 동일 한글(보통 무방).
- 충돌 대비 해시는 32비트+길이 병기.

## 배치 (WRAM)
- **훅 코드+번역테이블+한글글리프 = 새 파일**(예: KRHOOK.BIN) → 3씬 공통 free 영역 **0x06022488(15KB)** 또는 **0x060b5a00(13.8KB)** 로드.
- 부트로더(1ST.BIN 0x060145E0~ 시퀀스)에 로드 항목 추가(디스크립터+JSR 0x06015434).
- **글리프**: 폰트전략(docs/07)=씬별. 한글 음절을 글리프테이블 한자범위(0x100+) 슬롯에 씬 진입 시 로드. (초기 프루프는 단일 씬 하드코딩 가능.)

## 설치 패치 (X02.BIN 리다이렉트)
0x606ca26~ 명령을 훅 점프로 교체:
- 트램폴린: `MOV.L @(PC),Rn` + `JMP @Rn` + 딜레이슬롯 → my_hook. 덮은 명령([0x0607BB9A]=1 등)은 my_hook서 재수행 후 0x606ca2a 복귀.
- 정확한 바이트는 SH2 어셈블러(tools/sh2asm.py)로 생성.

## 구현 단계
1. ✅ 훅지점·free공간 확정.
2. SH2 미니 어셈블러(tools/sh2asm.py) — 훅 코드 정확 인코딩.
3. 훅 코드 작성·어셈블(해시+룩업+복사).
4. 번역테이블 생성(JP토큰해시→한글토큰) + 한글글리프.
5. 패치: X02.BIN 리다이렉트 + 1ST.BIN 부트로더에 KRHOOK.BIN 로드 + X2SAMPLE.MES 글리프.
6. 디스크 재빌드(xdelta) + 실기 테스트.

## 프루프 우선 (최소 훅)
전체 번역 전에 **1개 메시지 하드코딩 훅**으로 영구성 먼저 검증: 특정 JP 해시 매치 시 한글 복사. 성공하면 테이블 일반화.
